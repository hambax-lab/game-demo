# Как подключиться к игре

## Один раз: подготовка (10 минут)

1. Зарегистрируйся на github.com и пришли свой ник. Тебе придёт приглашение в репозиторий, прими его.
2. Установи Git: https://git-scm.com/download/win (на Mac он уже есть). Во всех окнах установщика просто жми «Next».
3. Установи приложение Claude (claude.ai/download), войди и открой вкладку **Code**.
4. Создай на компьютере пустую папку, например `Документы\game`, и выбери её в Claude как рабочую папку.
5. Вставь в Claude промт ниже. Когда Git попросит войти в GitHub, откроется браузер: войди и разреши доступ.

## Промт для первого запуска

```
Я работаю над web-игрой вместе с напарником. Я не программист, всё делаю через тебя.

1. Склонируй репозиторий <ССЫЛКА НА РЕПОЗИТОРИЙ> в текущую папку.
   Если Git попросит войти в GitHub, скажи мне, что нажать.
2. Прочитай CLAUDE.md в корне репозитория. Это наши правила, соблюдай их всегда.
3. Установи всё нужное для запуска и запусти игру у меня, чтобы я её увидел.
4. Коротко расскажи, как устроен проект и какая у меня зона работы по CLAUDE.md.

Дальше я буду просто давать тебе задачи. Каждое готовое изменение ты сам
проверяешь, коммитишь и пушишь в main, как написано в CLAUDE.md.
```

## Каждый день

Открывай Claude в той же папке и пиши задачу обычными словами: «сделай, чтобы герой прыгал выше», «поменяй музыку в меню на эту», «кнопка старта не нажимается на телефоне».

Claude сам возьмёт свежую версию, сделает задачу, проверит её и выложит. Через 1–2 минуты изменения появятся на сайте: **<ССЫЛКА NETLIFY>**.

Если Claude пишет, что ваши с напарником правки столкнулись, он спросит, какую оставить. Просто ответь.

Если на сайте что-то сломалось, напиши Claude: «на сайте сломалось после последнего изменения, откати».
